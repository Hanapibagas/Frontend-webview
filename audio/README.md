# Audio Files Directory

Tempatkan file-file audio adzan di folder ini.

## Struktur Folder:

```
audio/
├── adzan/
│   ├── mishary_rashid_alafasy.mp3      # Adzan Mishary Rashid Alafasy
│   ├── abdul_basit_abdusamad.mp3       # Adzan Abdul Basit Abdusamad
│   ├── maher_al_mueaqly.mp3            # Adzan Maher Al Mueaqly
│   └── simple_beep.mp3                 # Beep sound (fallback)
└── README.md                            # File ini
```

## Cara Mendapatkan Audio Adzan:

### Opsi 1: Download dari sumber terpercaya
- Search di Google: "download adzan mp3"
- Pastikan download dari sumber yang reliable

### Opsi 2: Convert dari YouTube
- Gunakan ytmp3.cc atau converter sejenis
- Paste URL video adzan dari YouTube
- Download sebagai MP3

### Opsi 3: Request ke saya
- Beritahu saya jika butuh bantuan mencari audio adzan yang bagus

## File yang Dibutuhkan:

1. **mishary_rashid_alafasy.mp3** (±1-2 MB)
   - Adzan oleh Mishary Rashid Alafasy
   - Suara merdu dan populer

2. **abdul_basit_abdusamad.mp3** (±1-2 MB)
   - Adzan oleh Abdul Basit Abdusamad
   - Suara klasik dan berwibawa

3. **maher_al_mueaqly.mp3** (±1-2 MB)
   - Adzan oleh Maher Al Mueaqly
   - Suara jelas dan mudah dimengerti

4. **simple_beep.mp3** (±10-50 KB)
   - Sound beep pendek sebagai fallback
   - Bisa dari: https://www.soundjay.com/misc/sounds/bell-ringing-05.mp3

## Tips:

- Pastikan file dalam format **MP3**
- Quality bitrate 128kbps sudah cukup bagus
- Jangan terlalu besar (max 5MB per file) agar app tetap ringan
- Nama file harus **PERSIS** seperti di atas (case-sensitive)
